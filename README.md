> **Un clásico juego de laberinto desarrollado desde cero utilizando la API Canvas de HTML5 y Vanilla JavaScript.**

🚀 **¡Juega la versión en vivo aquí!** 👉 [https://lufly28.github.io/juegodelaberinto/](https://lufly28.github.io/juegodelaberinto/)

## ✨ Características Destacadas
* 📈 **Sistema de Niveles:** Progresión de dificultad con 3 niveles diseñados a medida (Fácil, Medio, Difícil).
* 🧱 **Físicas y Colisiones:** Detección de colisión precisa que bloquea al jugador al tocar una pared, brindando una experiencia de juego fluida.
* 📱 **Multiplataforma (Responsive):** Jugable tanto en PC (usando las flechas del teclado o W,A,S,D) como en dispositivos móviles (mediante botones táctiles en pantalla).
* 🎨 **Interfaz Moderna (UI/UX):** Estilo "Dark Mode" con paleta de colores de alto contraste y ventanas emergentes (modales) para las pantallas de victoria.

## 🛠️ Tecnologías Utilizadas
* **Vanilla JavaScript:** Lógica de juego, matrices (arrays) para estructurar los niveles, detección de eventos del DOM y bucle de animación a través de `requestAnimationFrame`.
* **HTML5 Canvas:** Motor de renderizado dinámico para dibujar el jugador, la meta y las paredes.
* **CSS3:** Estilos flexbox, animaciones de transición y "Media Queries" para adaptar los controles según el tamaño de la pantalla.
